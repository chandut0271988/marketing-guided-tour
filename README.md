# Apartment community masterplan

Milestone 2: a procedural, interactive interpretation of the supplied apartment-community plan. This is a schematic marketing model, **not an architectural model or a dimensionally accurate survey**.

## Run

Requires Node.js 22.12+.

```sh
npm ci
npm run dev
npm run build
npm run preview
```

The application uses Vite, React, TypeScript, Three.js, React Three Fiber and Drei. React 19.2 is intentionally constrained to the version range supported by React Three Fiber. No backend or application state library is needed for this milestone.

## Included

- All 12 wings, generated by a single reusable `Wing` component from `src/data/wings.ts`.
- A ground storey plus 14 residential floors for 60–66 and 69–70; 11 for 67–68; 13 for 71. Basements are omitted.
- Building plinths, contrasting ground storeys, instanced floor bands, restrained façade accents, roofs and selectable HTML number labels.
- Approximate internal roads, site boundary, central garden spine, eastern forestscape, pedestrian paths and a southern water feature.
- Instanced vegetation (two meshes for all tree crowns and trunks), limited DPR, a single shadow-casting light and on-demand rendering.
- Aerial and plan views, orbit/pan/zoom, reset, selectable wings and a collapsible mobile information sheet. Arrow keys orbit when the scene has focus; +/− zoom; R resets. Camera transitions can be interrupted by direct manipulation, and respect reduced-motion preferences.

## Reference interpretation and assumptions

Both `docs/reference/masterplan.jpg` and `docs/reference/project-details.jpg` were reviewed before building the scene.

1. **Orientation:** the photograph is used as presented: −Z is its upper edge, +Z its lower edge, and +X is right. “Southern” describes the lower water-feature portion requested for this milestone. Geographic north has not been established from the photograph.
2. **Arrangement:** the left row runs 60, 61, 62, 63, 64 from top to bottom. The right row runs 70, 69, 68, 67, 66, 65. Wing 71 stands to their right near the forestscape. This preserves the plan’s broad relationships and numbering.
3. **Footprints:** the plan’s connected, notched building footprints and courtyards are simplified into separate rectangular wing volumes with small gaps. These are not representations of apartment layouts, actual separation distances or structural connections.
4. **Heights:** the supplied residential floor counts are preserved. A separate ground storey is added; floor heights and all other lengths are arbitrary diagram units. Neither the model’s footprint nor the forestscape has been calibrated to acres.
5. **Site:** boundary vertices, road widths, garden beds, lawns and paths are hand-traced approximations. Roads are flat ribbons; basement ramps, parking, adjacent property structures and terrain grades are omitted. The unlabelled upper-right area of the photo is excluded from the site.
6. **Landscape and water:** trees are a deterministic sampling, not a planting plan. The forestscape, open lawns and water outline are simplified from the image; the water is a flat, muted surface without simulation. Individual A–L amenity interactions are outside this milestone.
7. **Materials:** façade colors, floor articulation, roofs and landscape materials are design interpretations; no building elevations were supplied. No prices or availability are inferred. The displayed area and unit totals come from the project-details reference.

## Where to make changes

- `src/data/wings.ts`: wing positions, rotation, footprints, floor counts and heights.
- `src/data/site.ts`: boundary, roads, gardens, lawns, paths, water and camera bounds.
- `src/data/trees.ts`: deterministic planting placement.
- `src/components/Wing.tsx`: procedural geometry and a future `modelUrl` replacement point. Selection, labeling and camera state live outside the geometry. Optional GLBs are currently normalized to the configured envelope; align real asset units when architectural models become available.
- `src/scene/CameraController.tsx`: viewport-aware framing and constrained navigation.
- `src/ui/` and `src/app/styles.css`: accessible HTML controls and responsive presentation.

The scene is geometry-based and uses no image textures or external model downloads. Fonts are optional Google Fonts with local system fallbacks.
